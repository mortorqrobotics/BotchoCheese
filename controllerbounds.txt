Joystick1 Controller
--------------------
Left Stick Y/X: Field-centric translation drive (speed scaled by Left Trigger)
Right Stick X: Rotation/yaw drive (yaw speed scaled by Left Trigger)
Left Trigger (>= 0.25): Precision mode (translation 10%, reduced yaw)
A (hold): Drivetrain brake request
B (hold): Point wheels at left-stick direction
D-Pad Up (hold): Drive forward robot-centric at +0.5 m/s
D-Pad Down (hold): Drive backward robot-centric at -0.5 m/s
Left Bumper (press): Reseed field-centric heading
Right Bumper (press): Run StrafeToTag(drivetrain, 0.5) and RotateToTag(drivetrain, 0)
Y (hold): Shooter shoot command
X (hold): Feeder run command

Joystick2 Controller
--------------------
Right Bumper (press): Emergency stop
 - Cancels all scheduled commands
 - Stops Shooter motors
 - Stops Feeder motor
 - Stops Climber motors
 - Stops Intake + Pivot (via intake.stopAll())
Right Bumper (hold): Applies drivetrain brake request while held

No other Joystick2 bindings are currently configured in RobotContainer.java.
